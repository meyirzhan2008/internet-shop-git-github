# Онлайн дүкен (Internet Shop) ақпараттық жүйесі

Бұл жоба электронды коммерцияға арналған онлайн дүкен жүйесінің бастапқы құрылымын және талаптарын басқаруға арналған.

## Жоба құрылымы
* `README.md` - Жоба туралы жалпы сипаттама.
* `docs/requirements.md` - Жүйеге қойылатын функционалды және функционалды емес талаптар.
* `docs/use-case.md` - Пайдаланушы сценарийлері (Use Case сипаттамалары).
* `docs/diagrams/` - UML диаграммалары мен сызбалар сақталатын бума.
* # Жүйеге қойылатын талаптар (Requirements)

## 1. Функционалды талаптар
* Пайдаланушы жүйеге тіркеліп, жеке кабинетке кіре алуы тиіс.
* Каталогтан тауарларды іздеу және сүзгілеу мүмкіндігі болуы керек.
* Сатып алушы тауарды себетке қосып, тапсырыс ресімдей алады.
* Әкімші (Admin) тауарлар мен тапсырыстарды басқара алады.

## 2. Функционалды емес талаптар
* Жүйе тәулік бойы (24/7) қолжетімді болуы тиіс.
* Деректер қауіпсіздігі шифрлау протоколдары арқылы қамтамасыз етіледі.
* # Use Case Сипаттамалары

## UC-01: Тауарды іздеу және таңдау
* **Актёр:** Сатып алушы
* **Негізгі сценарий:**
  1. Пайдаланушы іздеу жолағына тауар атын жазады.
  2. Жүйе сәйкес келетін тауарлар тішін көрсетеді.
  3. Пайдаланушы тауарды таңдап, оның сипаттамасымен танысады.

## UC-02: Тапсырыс беру
* **Актёр:** Сатып алушы
* **Негізгі сценарий:**
  1. Пайдаланушы тауарды себетке қосады.
  2. «Тапсырыс беру» түймесін басады.
  3. Жеткізу мекенжайын енгізіп, төлем әдісін таңдайды.
